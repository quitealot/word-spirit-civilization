## 1. 当前基线

当前融合切片默认 debug 基线：

- 玩家 Max HP：`48`
- 敌人 Max HP：`60`
- 敌人基础伤害：`8`
- 水音：`18` 伤害 + 敌方下一击削弱 `20%`
- 回潮：`10` 伤害 + 回复 `22` HP
- independent / supported / failed：`1.00 / 0.70 / 0.40`
- no-call：独立配置 `0.40`

实机暴露的问题：在敌人 `60 HP / 8伤害` 的压力下，40% 的技能效果仍可能通过低伤害 + 回复长期磨过去，玩家没有充分感受到“英语发挥差 → 战斗效率低 → 敌人获得更多攻击机会 → 可能真正战败”的因果。

---

## 2. Sol 裁决：第一优先不改单次倍率

第一轮平衡**不先把 failed 从 40% 降到 20%**。

理由：

1. 一次答错仍应保留行动，不把零基础玩家训练成害怕犯错；
2. 40% 与 100% 本身已有明显技能组件差距；
3. 当前主要问题是敌人没有足够时间压力，低效率输出的代价没有兑现；
4. 单独降低 failed 会立刻制造与 `noCall = 0.40` 的规格冲突：无英语调用可能反而比答错更强。

因此第一轮只 Review：

- 敌人 HP；
- 敌人伤害；
- 由此产生的回合压力。

`1.00 / 0.70 / 0.40` 与 `noCall = 0.40` 暂时保持不变。

---

## 3. Phase B 平衡目标

本轮体验目标冻结为：

1. **全部独立正确**：明显顺畅，约 `4–5` 回合胜利；
2. **偶尔答错一次**：通常比全正确多承受约一次敌方行动，血量明显下降，但仍可挽回；
3. **连续答错两次**：进入危险血线，之后必须认真作答并做正确技能选择，否则容易战败；
4. **多次 failed / 依赖完整答案**：应正常战败，不能靠 40% 技能长期无脑磨死敌人；
5. **训练后立即再战**：从 40% 回到独立 100% 时，玩家能直接从伤害、回复、削弱和剩余 HP 感到明显改善。

核心体验原则：

> **答错仍能行动，但低效率会让敌人获得更多行动机会；一次失误可以救，持续低质量调用最终会真正输。**

## 6. 为什么 Candidate A 比直接降 failed 更合适

### 全正确

高质量英语更快结束战斗，因此少吃敌方行动。

### 一次答错

不是立即判死，而是因为伤害降低，敌人多活一回合，玩家多吃一次攻击。

### 连续答错

低伤害 + 较弱回复/削弱无法抵消敌方行动，危险自然累积。

### 训练后再战

同一个技能从：

- 水音 `7伤害 + 8%削弱` → `18伤害 + 20%削弱`
- 回潮 `4伤害 + 9回复` → `10伤害 + 22回复`

在更有压力的敌人面前会转化成真实的回合数和生存差异。

## 8. Candidate A 必须观察

1. 全 independent 是否稳定在约 4–5 回合且不显得过险；
2. 单次 failed 是否明显增加敌方行动代价；
3. 连续两次 failed 是否进入危险血线；
4. 持续 failed 是否正常战败；
5. 正确使用回潮是否能成为真实的“救回来”选择；

7. 是否产生“答错一次就害怕”的反效果。

若第 7 项出现，优先微调 Phase B 敌人压力，不改为 `0伤害 / 跳过回合`。

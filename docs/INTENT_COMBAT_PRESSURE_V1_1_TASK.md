# Intent Combat Pressure V1.1

状态：`AUTHORIZED BY USER PLAYTEST / NARROW BALANCE REVISION`

## 问题

当前玩家48 HP，而敌方循环为12/18/蓄力24。普通攻击已频繁接近玩家生命的四分之一到二分之一，使低血量时只剩回复或护盾这一道答案，敌方意图因此制造的是“假选择”。

## 本轮唯一改动

- 玩家HP、敌人HP、三技能、英语奖励、repair和回合展示不变；
- 敌方循环从 `12/18/蓄力24/24` 收敛为 `8/12/蓄力18/18`；
- 普通攻击只累积压力；明确蓄力重击才显著要求防守；
- 击杀后敌人不行动仍遵循既有回合顺序，不引入同时结算、速度条或濒死反击。

## 验收

1. 玩家在普通攻击前仍可合理选择进攻；
2. 蓄力回合保留防守价值；
3. 独立正确的离散奖励仍明显改善承伤、回复或护盾；
4. 答错仍记录真实weakness并进入既有repair；
5. 不修改EP01–EP03、主线战斗、正式V2倍率或5505词源。

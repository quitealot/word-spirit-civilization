# 《语灵》敌方意图战斗独立样机 V1 Sol Review

状态：`PASS AS NEW COMBAT BASELINE / MAINLINE MIGRATION NOT AUTHORIZED`

日期：2026-08-30

## 裁决

Intent Combat V1通过工程与产品原型Review，可作为下一阶段《语灵》战斗设计的基线；Candidate A–C继续只作历史学习闭环证据，不再作为正式战斗骨架继续调参。

本轮通过的不是最终数值，而是职责结构：

- 敌方意图先制造问题；
- 三个技能提供不同回答；
- 英语调用追加技能各自的离散掌握奖励；
- failed只保留技能基础职责，不显示统一发挥百分比；
- 蓄力窗口、水音压制、静波护盾与回潮续航形成可预测选择；
- 战斗层拿掉英语后仍能成立。

## 实机中发现并已修正

1. 最初水音压制在蓄力回合被浪费；现改为保留到敌方下一次真正攻击并在攻击后清除。
2. 最初纯战斗模式仍显示掌握奖励说明；现已完全隐藏，只保留基础技能结果。
3. 最初一次回合需要4–5次“继续”；现收敛为两段确认，兼顾可读性与节奏。
4. 手机模式切换按钮由39px提高到44px。
5. 新模块曾复制正式targetGloss；现已改为从 `ZERO_BASE_WORDS` 唯一来源派生。

## 保留风险

- 当前敌人只有两类意图，足以验证骨架但不足以证明长期耐玩。
- `water/help`直接用于独立样机，不代表已完成教学证据接入。
- 三技能数值仍是纸面原型值，不是正式平衡。
- 精英/Boss蓄势打断尚未实现，避免同时验证过多变量。
- 视觉仍是工程原型，不代表正式战斗美术与动画。

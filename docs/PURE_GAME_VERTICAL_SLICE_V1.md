# 《语灵》纯游戏版：首个商业验证切片

## 1. 已确认的方向与未确认的细节

用户明确要求完全不与英语学习相关，目标是微信小游戏中的立绘、回合制、收集、探索与故事；希望形成收入，同时让玩家开心、愿意耐心观察、不被焦虑驱动。

这不是“英语可选模式”，不与模拟世界Lite共享学习资格或数值奖励。
英语原型保留为历史实验，不删除、不继续扩建。EP01–EP03继续冻结，尚未批准主线迁移。
本文件中的具体队伍规则、内容量、战术方案属于Sol建议，不是已获玩家验证的正式设定。
不把助手以前提出的语言起源世界观、进化因果或商业化建议自动升级为正式内容。

## 2. 一句话产品

通过探索结识语灵、组建小队、观察敌方意图完成回合战斗，并期待伙伴下一阶段成长的轻量剧情RPG。

暂定测试人群：喜欢生物伙伴、收集与慢节奏策略的玩家；不能把原英语学习者默认当作现成游戏用户。
“更平静”是体验目标，不宣称训练耐心、改善心理健康或具有治疗效果。

## 3. 最小可体验范围

首轮目标12–20分钟，不制作几小时长篇、不先写庞大故事线。
原先讨论的“3只起始+2只新收集”缩为：1只起始、1只途中加入、1只后续可遇见的预告。
优先复用已有芽语、澜歌、烬尾美术；具体谁起始、谁加入由素材/剧情适配审查决定，不擅自改变冻结登场顺序。
独立试验可使用系统说明与测试标识，但不得伪造正式剧情。正式对白、加入因果、进化命名缺口一律PENDING_K3。

| 段落 | 操作与结果 | 要验证的欲望 |
| --- | --- | --- |
| 出发（约2分钟） | 看到一只完整语灵立绘，明确本次探索目标 | 愿意带着它出门 |
| 探索（约3分钟） | 小型节点图选择岔路，发现可回访的线索 | 想看另一条路 |
| 初战（约2分钟） | 看懂意图，主动做一次进攻或防守决策 | 想再打一场 |
| 结识（约3分钟） | 完成一个确定条件后第二只加入图鉴与队伍 | 想收集伙伴 |
| 首领（约3–5分钟） | 新伙伴提供真实的新解法，而不是只有战力上涨 | 组队有价值 |
| 回营（约2分钟） | 看见本次发现、伙伴变化与下一目标 | 期待下次探索 |

共1张小节点图、1处岔路秘密、2场必经战斗、最多1场可选战斗、1次伙伴入队。
岔路不互相永久锁死，不强制限时；离开可恢复当前节点。首领输后可重试，不损失已收集伙伴。
进化征兆只使用已有获准资产/文案；资产不足时明确标成待制作，不用“完整进化已实现”虚假验收。

## 4. 战斗提案：少量规则，实际有选择

- 技能直接发动，不存在答题、mastery倍率、no-call或weakness repair。
- 一场战斗不以固定强制防守顺序作为唯一解，不用敌伤暴涨制造策略。
- HP清楚可见；HP归零判胜负；普通战斗不再叫“逼退”。
- 先显示玩家技能结果，再显示敌方结果；不用每条伤害都另点一次继续。
- 提案队伍为2只、1只在场：换位作为一次行动；防守效果的归属与持续时间必须先在专项战斗任务中写清。
- 每只首轮只验证2个有区别的技能；具体数值另建纯游戏配置，不直接套旧英语V2或删除英文题后保留其平衡。
- 普通攻击制造累积压力，蓄力重击事前可读；无答题倒计时、无反应速度惩罚。
- 不新增属性相克矩阵、随机装备词条、速度条、联机PVP、抽卡、体力、每日任务或进化树编辑器。

验收不只看“可以打赢”：至少两条不同的合理技能/队伍路线可通关；同时检查无脑攻击、无限治疗、无限护盾是否成为唯一最优策略。
首领必须给第二只伙伴一个可见价值；若换位只是拖时间，就删掉换位提案，不额外叠系统补救。

## 5. 收集、探索与舒适感

首只新伙伴采用确定性获得，不做随机抽取或付费概率。明确显示“发现—结识—加入”，图鉴由行动填充。
每条岔路有可感知结果，不靠十个相同宝箱凑探索。首次相处用短事件，不靠大量说明书。
允许暂停、离开、回来；不签到惩罚、不资源腐烂、不限时倒计时促销。
不把“防守次数多”视为人格好，不做隐藏道德分数，不把某个进化形态定义为人格优劣。

## 6. 商业验证与停止线

本切片不接收款、不投放广告、不建假购买成功页。先验证兴趣和重复游玩，再决定收费方式。
试玩后可单独展示明确写有“概念测试，未售卖”的外观/章节方案；点击意愿不等于真实付费转化。

首轮找10–30名非开发团队成员；朋友意见与陌生玩家行为分别记录。
记录开始、完成、选择岔路、入队、战败/重试、退出节点、主动再次打开。
只采必要测试信息；真实遥测采集前另审隐私与存储方案，不提前上线追踪。

| 问题 | 判断依据 |
| --- | --- |
| 有趣吗 | 无讲解能完成；主动尝试不同操作；不只赞美图片 |
| 想收集吗 | 自发查看图鉴、追问第三只、让第二只出战 |
| 有探索欲吗 | 主动回访岔路，不只是跟箭头点击 |
| 更舒适吗 | 玩前后自评与开放反馈；允许紧张但不感到被催促 |
| 值得继续投资吗 | 非熟人也有继续玩和返回行为；艺术内容成本可承担 |

先前讨论的70%完成率、30%次日留存等只是候选内部目标，不是行业基准。
20分钟一次性内容不足以证明七日留存；没有可重复内容时，不拿D7作为虚假商业PASS。
小样本须报告人数与原始计数，不能把30人试玩推导成盈利预测。
若只觉得立绘好看，不愿战斗、收集或回来：先改核心循环，不扩地图、不批量产语灵。

## 8. 实施顺序

M0（本轮）：记录转向、范围、GitHub与官方文档先验、资产与风险。无运行改动。
M1（下一步技术验证）：真实微信运行时中完成立绘、三按钮、1场无英语战斗、存档恢复和切后台恢复。
M2：只有M1通过，才制作上述探索—入队—战斗—回营的同一个连续切片。
M3：真实玩家测试与Sol审阅；产品反馈由用户最终裁决，不自行宣布商业成功。

后续工程任务必须单列允许路径、输入数据、结算顺序、存档键、类型检查、测试用例与停止线。
不允许再次创建一批只有各自菜单的独立样机后宣称完成完整游戏。
路线为微信小游戏；网页仅可作为辅助预览，不得把Sites网址或WebView截图当微信真机验收。

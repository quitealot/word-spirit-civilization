# 焰尾近身动作 V2

用户明确否定站桩/远程尾焰，要求跑过去、用尾巴攻击、再跳回来，已授权执行。基线22872ee / Site36。

只改焰尾演出，不改40伤害、冷却、蓄火倍率、火星/蓄火、澜歌、BOSS、主线与存档。
新增四姿势图仅用于焰尾：跑动伸展/收腿、转身尾击、左向回跳；常驻原立绘不换。原远程尾片仅留给火星，焰尾不再发射离体尾巴。
总长3200ms，5–28%跑近，28–40%转身尾击，40%（1280ms）命中，40–45%接触停顿，50–78%回跳，86%（2752ms）回位站稳，100%后敌方准备。场地百分比位移适配大小屏。
姿势图预加载，确认出手时捕获可用性，不允许中途加载成功导致动作切换；失败回退原画简化移动并显示说明，不阻断战斗。减少动态保留原画并直接展示结果。
手动模式焰尾回位前禁止推进及提前揭示结果；正常自动仍按完整演出等待。计时清理、切换、重开不写战斗数值。
范围：fire-battle接线、独立tail-melee组件/时间表/CSS、新素材、新validator与文档；旧fire-model包括历史时间表保持原样，仅展示resolver覆盖tail。完成验证和发布后停止，不扩其他技能。

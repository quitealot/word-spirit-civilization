# EP01–EP10制作级内容稿

## 使用方法

本文件是制作层覆盖稿。所有角色逐句对白引用[正式v1.1第5节](../ten-episode-demo-spec-v1.1.md#5-ep01ep10完整剧情与自然对白)，不得在实现时从本文件“补写相似台词”。制作单位固定为：背景 + 立绘/状态 + 对话 + 固定互动 + 战斗 + 轻特效 + 地图节点 + 少量CG。

统一状态：`LOCKED → AVAILABLE → IN_PROGRESS → COMPLETED`。关闭对话、退出战斗或刷新时保存当前节点；失败保留学习结果，不完成剧情节点。

## EP01｜第一伙伴

- 制作目标：玩家在3分钟内做出一次真实三选一，并感到“是双方选定”。
- 场景：`BG_STATION_INTERIOR`；岑婆普通/训斥；三初伴观察/靠近。
- 节拍：烬尾闯祸轻移 → 玩家进门 → 依次查看三只 → 玩家确认 → 初伴靠近/共鸣微光 → 3个L1教学 → 阿洛敲门 → 港外旧路解锁。
- 交互：查看三只不等于获得；最终按钮只提交一只。选定后从该初伴专属回应继续，禁止重播选择前对白。
- 学习：教学只取`choose/grow/habit`的L1；结束后可继续学习，也可完成对话。
- 奖励反馈：`starter_selected`、图鉴“初伴”、下一形态“？？？”。
- 验收：三条路径均可完成；刷新后只保留所选一只；选伴后无首页闪现或剧情倒带。

## EP02｜雾散以后

- 制作目标：把学习产生的探索力转化为“我能再走一步”，不展示词数门槛。
- 场景：`BG_OLD_ROAD`；阿洛普通/警觉；雾层淡出。
- 节拍：旧路闲谈 → 系船桩 → 河道往事 → 检查探索力 → 新脚印 → 初伴警觉 → 石门轮廓。
- 交互：探索力不足时保留现场，只显示“今日学习/到期复习”软引导；达到阈值后原地继续。
- 奖励反馈：地图相邻节点“苏醒之门”显形，门前黑影闪过一次。
- 验收：不得弹“再背N词”；新词、到期复习或纠错均可提供推进来源。

## EP03｜苏醒之门

- 制作目标：第一次证明“英语控制发动质量，语灵决定技能效果”。
- 场景：`BG_AWAKENING_GATE`；蚀影A；三初伴战斗态；石纹微光。
- 节拍：门前对话 → 蚀影出现 → 首战教程 → 战后互损 → 门纹亮起 → 门开一线。
- 战斗：选语灵/技能后才取题；优先到期词，错词可优先复现。当前无通过Review的L2/L3时只出L1。
- 失败：保留题目证据；可重试或退出，不降低词汇永久进度。
- 奖励反馈：残页回廊解锁；错词显示“很快会再遇见”。
- 验收：三初伴任一路径通关；换初伴不改变题型；战斗中位目标90–150秒。

## EP04｜回廊里的尾巴

- 制作目标：用两次局部目击建立“我想知道它是谁”，不急着发伙伴。
- 场景：`BG_PAGE_CORRIDOR`；残页物件；第二伙伴候选的尾巴/眼睛局部态。
- 节拍：回廊完整性 → 石子声/尾巴第一次闪过 → 残页互动 → 柱后露眼第二次 → 初伴靠近 → 远处多只脚步声。
- 交互：残页只允许“查看/放下”，不让玩家抠取；未知语灵不可追逐、不可捕捉。
- 图鉴：`MIST_PORT_SPIRIT_01`，名称未知，目击2/3，仅轮廓。
- 验收：第二伙伴正式候选未冻结前，只替换同一占位资产槽，不改剧情触发。

## EP05｜寂静广场

- 制作目标：让玩家先关心群落安全，再完成第三次目击。
- 场景：`BG_SILENT_SQUARE`；两种普通野生语灵；蚀影B；草、碗、晾绳前景。
- 节拍：生活遗迹 → 野生语灵探头 → 发现它们在怕身后 → 蚀影战 → 检查同伴 → 翻碗排水 → 第二伙伴远处跟随。
- 战斗：当前FSRS题池；仅当某题内容与玩家Mastery均合格时才可出现L2，比例上限25%。
- 奖励反馈：目击3/3；按钮文案“下一次，等它自己靠近”。
- 验收：战后必须有翻碗这一生活化动作；不出现捕捉按钮。

## EP06｜它还在跟着

- 制作目标：通过“玩家停下等待”而非捕捉获得第二伙伴。
- 场景：复用回廊出口/旧路小坡；第二伙伴完整立绘；共鸣微光。
- 三段固定互动：玩家靠近→它躲；初伴靠近→它观察；玩家原地等待→它自己走近。
- 共鸣：按钮“尝试共鸣”；成功后展示完整立绘和占位/冻结后的正式名。
- 初伴反馈：芽语递叶、烬尾转脸但尾光亮、澜歌让位并轻拍水纹。
- 队伍教学：最多3只，当前2只；只教学前后位与换位，不为未冻结伙伴临时编技能。
- 成长反馈：初伴共鸣首次明显纹理变化；下一形态仍为“？？？”。
- 验收：不自动补第三只；退出短战后可断点重试；第二伙伴获得状态不重复播放。

## EP07｜第一次并肩

- 制作目标：第一次感到两只伙伴真的在配合。
- 场景：复用广场北路；双蚀影组合；旧碑远景。
- 节拍：两只蚀影挡路 → 阿洛嘴硬 → 战斗必须完成一次换位 → 战后复盘配合 → 发现旧碑。
- 战斗：换位不出题，每2回合最多一次；题层仍由玩家Mastery和已Review内容决定。
- 奖励反馈：两只语灵成长动作；初伴共鸣第二次反馈；无名碑节点解锁。
- 验收：不要求第二伙伴回答专属题；只用两只即可完成。

## EP08｜被抹掉的名字

- 制作目标：建立长期异常，但不解释是谁、为什么或名字的机制。
- 场景：`BG_NAMELESS_STELE`；`CG_STELE_CLOSEUP`；石屑轻落。
- 节拍：分辨风化/人为凿痕 → “港”残字 → 背面名字排列 → 只抹一行 → 远处固定金属声 → 旧擂台节点出现 → 决定记住位置。
- 交互：石碑可查看正/背面；不允许玩家自动补名。
- 竞技：只开放入口，不强制进入；无后端时必须标“测试守擂记录”。
- 奖励反馈：石碑CG显示未凿净的首笔；拓片待岑婆查看。
- 验收：不得解释大失语；不把“一个名字”推断升级为确定答案。

## EP09｜雾里的稀客

- 制作目标：同时验证追踪欲、稀有收藏欲和天空传说好奇心。
- 场景：旧擂台外侧/雾坡复用；稀有语灵；`CG_SKY_SILHOUETTE`。
- 三个固定追踪点：石阶、断墙、水洼；每处2–3道到期/抽检题。实际层级按Mastery降级。
- 节拍：鳞粉 → 脚印 → 三处追踪 → 稀有完整出现 → 主动试探战 → 看向天空 → 巨大剪影掠过 → 稀有跃入雾中。
- 结果：胜利不掉落、不捕捉；稀有图鉴“未共鸣·线索1/3”；天空只记`SKY_LEGEND_01`轮廓。
- 验收：不可出现SSR、掉率、卡池或预购；稀有离开后仍留下“雾浓时可能再遇”。

## EP10｜雾中的回声

- 制作目标：检验记忆与队伍闭环，用具体阻拦结束序章，不解释异常。
- 场景：`BG_GATEKEEPER`；守门人普通/收武器；旧牌；Boss轻特效；`CG_CHAPTER_MAP`。
- 节拍：守门人要求回去 → 询问石碑 → 三选一“带回了什么” → Boss → 收武器 → 今天仍不能过去 → 说明有人未归 → “至少别再把它们忘掉” → 章末地图。
- Boss：唯一规则以[EP10 Boss制作稿](./ep10-boss-production-spec.md)为准；阶段上限不是强制题层，必须按玩家真实Mastery向下适配。
- 章末三钩子：初伴下一形态变化、稀有线索1/3、无名碑拓片待查看。
- 验收：2只队伍可通关；Boss三次内完成率目标≥85%；守门人不回答谁抹碑/为何忘/名字机制。

## 全集共同验收

- 不打竞技可通关；不获得稀有可通关；初伴不正式进化。
- 对话快进/关闭后可断点续玩；动作全部可由立绘切换、轻移、音效字和轻特效实现。
- 每集结束必须至少给一种可见反馈：地图节点、图鉴状态、伙伴动作、共鸣变化或具体物件。
- 逐句对白验收时以v1.1原文为准，任何删改必须在GitHub Review中显式提出。

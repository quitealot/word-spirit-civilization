# 等级/经验 + 共鸣制作稿

状态：等待Sol Review。正式升星后移，本Sprint不设计升星材料或付费入口。

## 试玩目标

玩家在十集内能感到“伙伴在变强”和“它与我更熟”，但英语掌握不被数值替代；主动问下一形态是核心验证之一。

## 等级与经验

- 试玩等级范围建议Lv.1–Lv.8，所有阈值配置化。
- 经验来源建议权重：首次正确L1 10、到期复习正确8、错词纠正正确6、普通战完成20、Boss完成50。数值仅为Review起点。
- 答错仍记录学习证据，不扣经验、不掉级；重复刷同一无效按钮不产经验。
- 等级只影响生命、基础攻击和技能数值，不改变题层、不跳过到期复习、不提升Mastery。
- 升级反馈控制为一次短光效 + 数字 + 一句具体伙伴状态，不中断连续学习超过2秒。

## 共鸣

- 共鸣是“玩家与单只语灵共同完成有效学习/战斗”的长期关系值，不等同经验。
- 有效来源：与该语灵共同完成首次学习、到期复习、错词纠正、关键剧情战和换位配合。
- 不公开精确进化倒计时；内部阈值配置化，UI只显示纹理/动作变化与模糊阶段。
- 试玩阶段建议三个可见节点：EP06第一次明显变化；EP07并肩后的第二次反馈；EP10后出现新的进化征兆。
- 初伴与第二伙伴分别记录共鸣；新伙伴加入前不能继承初伴共鸣。

## UI状态

| 状态 | 玩家可见反馈 | 禁止项 |
|---|---|---|
| 初识 | 初伴标签、轻微呼吸/尾光/水纹 | 精确进化条件 |
| 熟悉 | 主动看向玩家、详情页出现新纹理 | “再背N词升级” |
| 并肩 | 换位/援护时有组合动作 | 题型专属加成 |
| 征兆 | 下一形态仍为？？？，局部轮廓变化 | 试玩内正式进化 |

## 数据与埋点

- `xp_gained`：spiritId、source、amount、wordId可选。
- `level_up`：spiritId、fromLevel、toLevel、source。
- `resonance_gained`：spiritId、source、delta、episode可选。
- `resonance_feedback_seen`、`evolution_hint_opened`。
- 投资Review看玩家是否主动打开进化提示≥2次、是否主动追问下一形态；不以总经验量替代兴趣指标。

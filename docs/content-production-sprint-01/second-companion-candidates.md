# 第二伙伴3候选设计

状态：全部为`PROPOSED`。三案共用占位ID `MIST_PORT_SPIRIT_01`，Sol只可选择其一进入正式设计；未选择前不得写入主线正式名。

## 共同剧情适配条件

- EP04第一次只露尾巴，第二次从柱后露眼；EP05远处跟随；EP06因玩家等待而主动靠近。
- 轮廓必须与三初伴明显不同，小尺寸、低威胁、能在静态立绘中表达谨慎。
- 定位服务双伙伴配合，但技能与题型完全解绑。
- 不承担“大失语”解释，不会说人话，不具备稀有/传说标签。

## 候选A｜页狸（推荐进入Sol比较，不代表冻结）

- 核心记忆点：像小型貂/狸的灵巧语灵，尾巴由三层柔软“页片”组成，奔跑时像翻书。
- 色彩：旧纸米色、墨绿耳尖、少量雾蓝纹；避免真的做成纸制品。
- 性格：警惕、爱观察、不喜欢别人碰残页；会把碎页推回干燥处。
- 战斗定位：机动辅助。候选技能概念为轻击、把同伴拉回安全位、给下一次行动提速；名称待冻结后另审。
- 三次目击：页尾闪过 → 柱后露眼且尾片收紧 → 广场远处用尾巴盖住受潮物件。
- EP06共鸣动作：靠近初伴，先用尾尖碰其脚边，再站到玩家侧后方。
- 优点：与“残页回廊”强记忆绑定，尾巴钩子最自然；缺点：主题过强时可能让玩家误以为它掌管词/书页。

## 候选B｜砾耳

- 核心记忆点：短腿、长耳，耳缘像薄石片；移动时会有轻微碎石声，尾巴是柔软的圆锥形。
- 色彩：暖灰石色、苔绿背纹、琥珀眼。
- 性格：胆小但会确认危险来源；不喜欢开阔地，常贴柱脚移动。
- 战斗定位：防护/扰动。候选技能概念为撞击、挡下一次伤害、制造短暂尘雾；名称待审。
- 三次目击：石子落地后尾尖缩回 → 长耳从柱后出现 → 广场战后在远处踩住松动石块提醒玩家。
- EP06共鸣动作：玩家原地等待后，它把一颗小石推到玩家面前再靠近。
- 优点：生活化、低魔法感、与回廊声音线索契合；缺点：第一眼收藏欲可能弱于页狸。

## 候选C｜苔灯兽

- 核心记忆点：小型蜥/兽混合体，背上有一簇不发强光的湿苔，尾端在紧张时亮起微弱暖光。
- 色彩：深青、潮湿苔绿、暖黄尾光。
- 性格：慢热，会留在受伤同伴附近；越害怕尾灯越暗，而非越亮。
- 战斗定位：恢复/持续支援。候选技能概念为轻击、缓慢恢复、降低下次伤害；名称待审。
- 三次目击：暗处尾光闪灭 → 柱后只见一只眼与苔光 → 广场战后停在受伤野生语灵旁。
- EP06共鸣动作：先接受澜歌水纹/芽语叶片/烬尾尾光，再主动靠近玩家。
- 优点：情绪反馈直观，轻特效产能低；缺点：与澜歌恢复定位可能重叠，需要技能差异化。

## 建议Sol评审维度

1. 玩家看见EP04尾巴时是否想追；2. 与三初伴轮廓是否区分；3. EP06“主动靠近”是否可信；4. 双伙伴定位是否互补；5. 是否会误导题型绑定；6. 美术状态能否控制在普通/警觉/共鸣三张以内。

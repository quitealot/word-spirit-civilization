# 单语灵战斗 UI 样机

2026-08-31 用户授权：以用户指定旧雾港图为基准，场上仅一只我方语灵、一个敌方目标；加强血条、技能图标和介绍；可点选、确认施放、分段展示结果。不再仅生成静态图。

范围：新增 `/prototype/battle-ui`、路由局部CSS/模型/验证、原素材的清理副本及本交接。不得改主线、旧原型、存档、成长或词源。不新增正式敌人/剧情；守门人沿用占位并注明 `PENDING_K3`。换灵只列出后备，不开放未经授权的其他技能。

数值仅为UI演示夹具：按V2规格表显式复制澜歌三技能（水音18伤害/20%下一击削弱；回潮10伤害/22回复；静波10回复/30%下一击减伤）。采用现有Phase A 48/60/8生命与敌伤；无英语、无倍率。它不是新的正式战斗基线，也不修改Intent Combat或旧V2实现。详情与演示共用同一配置；不能把缺失组件用文案掩盖。

回合：选择→详情→确认→玩家结果(1.4s)→敌人准备(1s)→敌人结果(1.4s)→下一回合。支持暂停/逐步继续；HP归零明确胜负，击杀后敌人不行动。单次减伤按V2次序：削弱→减伤→Math.round→HP。回血先显示，不能与敌伤糊在一起。计时器卸载清理，忙时拒绝重复提交，键盘/减少动态效果可用。

视觉：原墨绿/旧金、原雾港构图，背景只清除原图内烘焙的三只角色。全新副本不覆盖原文件；清理稿由图像编辑生成，需记录细节漂移风险。每个技能有功能图标、作用、数值和确认动作。头像/HP与场上模型区分；血条粗、有边框/刻度、伤害残留段、实际HP数值。未指定浏览器实机测试，本轮做模型测试、类型检查、lint/build及HTTP渲染检查，不虚报点击或手机实测。

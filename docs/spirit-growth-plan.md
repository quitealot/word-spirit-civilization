# 词灵成长方案

## 队伍与获得

- EP01三选一，只得芽语、烬尾、澜歌之一。
- EP01–05正常只有1只；EP04–06三次目击后，`MIST_PORT_SPIRIT_01`在EP06自行靠近并共鸣。
- EP06后正常2只；探索活动未来最多3只。不补NPC、不强制满编。
- 普通伙伴靠信任获得，不使用捕捉球或抽卡；稀有语灵试玩只完成线索1/3，默认不获得。

## 技能原则

- 语灵决定技能效果，学习引擎决定题目层级。
- 任意初伴均可遇到L1/L2/L3，不存在“芽语=词根、烬尾=词义、澜歌=填空”。
- 换人本身不出题，正式设计每2回合最多一次。

## 四条成长线

1. 等级：学习与战斗经验影响基础数值，但不能替代英语作答。
2. 星级★1–★5：由稳定掌握、7日保持率、平均识别速度和陌生文本覆盖率驱动，不售卖升星。
3. 技能：等级/剧情解锁；升级只改变效果，不减少学习要求。
4. 共鸣：玩家与单只语灵共同学习和战斗的长期关系值，通过动作、纹理和轻特效表达。

## 进化预告

- 试玩中初伴不完成正式进化，只出现明显征兆。
- EP06、EP07、EP10提供可见共鸣反馈；界面始终显示下一形态“？？？”。
- 不展示“再背32词进化”之类精确倒计时。

## 当前实现差距

- 初伴技能按钮与效果骨架存在；未实现等级、星级、技能升级和真实共鸣数值。
- 第二伙伴只有占位ID/轮廓/共鸣状态，没有设计稿，因此没有名称、技能或属性。
- 双伙伴只实现显示和换位演示，不是完整1–3只战斗系统。

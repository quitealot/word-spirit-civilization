# 烬尾去程跑步姿势修正

用户反馈：攻击去程仍像倒跑。根因：旧run-a/run-b身体胸口/前腿向左，头扭向右；仅按鼻尖朝向验收错误。

本轮范围（用户后续补充）：新增独立正常战斗待机图，并修正焰尾去程两个跑步帧。头、颈、胸、前爪必须整体朝右，臀部/后腿/尾巴在左；禁止回头式姿势。待机四脚站稳，展示立绘保持不变。保留现有扫尾和朝左正向回跳、回位后面向敌人的顺序。伤害/时间/冷却/其他技能机制/主线不变。

长期美术规则：展示立绘可以歪头、摆姿势，突出角色个性；战斗待机必须正常自然站立、面向对手。技能动作从战斗待机出发并回到待机，不以拖动展示立绘代替身体动作。后续语灵同样遵守，但本轮不开始第三只语灵。

素材要求：同一角色、金色胸饰、火焰冠与长焰尾、原画风；两格等尺寸、相同基线、真透明、边界不串帧。生成结果不通过则不替换在线素材，不手动去底伪装生成成功。

接入方式：新跑步图与旧扫尾/回跳图分开，等待两张都解码后才使用完整姿势；保持一次施放开始时锁定素材就绪状态，避免半途换图。SVG每格继续显式裁切。

验收不再只检查transform或鼻尖方向：必须看胸口与前后腿关系、尾根位置，再检查去程/回程移动。静态素材检查不能代替动态试玩。

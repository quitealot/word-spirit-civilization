# 10关试玩内容方案

## 核心循环

`看伙伴状态 → 学习/复习 → 获得探索力 → 点击地图节点 → 对话/战斗 → 收集或成长反馈 → 留下下一次钩子`

学习包与剧情集永久解耦；禁止“背完本集8词才能看剧情”。产品形态是界面驱动的精灵收集养成RPG，不做3D开放世界、自由移动、生态AI、生死繁殖或复杂动画。

## 剧情硬约束

- 岑婆务实嘴损；阿洛好奇冒失但会确认同伴；NPC不知道自己活在“世界观”里。
- 序章只制造异常，不解释“大失语”。守门人不知道谁抹碑、为何遗忘或名字意味着什么。
- 保留“至少别再把它们忘掉”，但禁止“古老力量苏醒”“文明复苏”“更大的秘密”等抽象AI对白。
- 占位语灵保持ID，不由Codex命名、编技能、稀有度或进化形态。

3. EP04–10在正式美术前只验证节奏、钩子和死路，不以占位视觉评价投资价值。

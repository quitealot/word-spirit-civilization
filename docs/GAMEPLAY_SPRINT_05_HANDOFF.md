# Gameplay Sprint 05 — Learning × Adventure Bridge

## 本轮目标

只解决学习与闯关之间的因果断点：玩家应当知道为什么现在学习、准备词在哪里再次出现、学习后冒险发生了什么变化。

## 已实现

- 地图节点区分 `行动准备 / 继续准备 / 可出发`。
- 每集首次准备时生成独立探索词池：最多3个本集新词、最多2个FSRS到期复习词。
- 准备进度和词池写入v5正式存档，关闭或刷新后可继续。
- 完成全部准备词后单独显示“准备完成”，不会直接切入剧情。
- 未准备完成的章节不能从地图出发。
- 战斗和EP09必要英语行动优先复现尚未调用的本次准备词。
- 非战斗章节通过一次轻量必要英语行动完成即时调用，不生成新题型。
- 题目明确标记“本次准备词”。
- 即时调用只记录本次探索的调用/成功证据；每次答案仍独立写入FSRS，未建立第二套长期调度。
- 章节结束显示准备词、成功调用、仍需复习、伙伴当前成长与地图推进。
- 旧EP01剧情中途学习模块退出流程；主要学习统一前移至章节出发前。
- 正式剧情、对白和K3内容接口未修改。

## 本地人工回归证据

使用已有存档验证EP02完整链：

1. 地图显示“行动准备”。
2. 准备页显示3个新词、2个到期复习。
3. 完成后地图变为“可出发”。
4. 刷新后“可出发”保持。
5. 探索必要行动复现准备词 `reach`，并显示“本次准备词”。
6. 结算显示：准备词5、成功调用1、需要再次复习4、伙伴成长、`港外旧路 → 石门`。

## Sol真人验收问题

1. 我为什么刚才要学习这些词？
2. 我刚才准备的词在哪里用到了？
3. 准备完成后，这次冒险发生了什么变化？

任一问题无法自然回答，则Sprint 05不应PASS。

## 未扩展内容

- 无新题型、战斗机制、L2/L3运行时、真实竞技、升星、后端或正式剧情文本。
- 探索即时调用不代表长期掌握，FSRS仍是唯一长期复习调度来源。

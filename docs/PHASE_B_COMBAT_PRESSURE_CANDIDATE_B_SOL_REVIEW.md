# 《语灵》Phase B Candidate B Sol Review

状态：`NOT PASS / FEEDBACK CLARITY HOLD / LOW-QUALITY EFFECT HOLD`
日期：2026-08-28
验收对象：Phase B 独立连续切片 Candidate B（玩家48 / 敌人80 / 敌伤14）

## 1. 结论

Candidate B **暂不通过**。

当前问题不能简单归因于“敌伤仍不够”。Candidate B 的数值压力已经接近目标，但玩家在低质量调用时无法清楚读懂“技能先发生什么、敌人随后造成什么、自己的净代价是什么”。

当前真实体验问题：

- failed 40% 使用「回潮」时，技能先产生约 `4伤害 + 9回复`；
- 随后敌方造成约 `14伤害`；
- 数学净结果通常约为 `-5 HP`；
- 但玩家先看到明显回血，约 700ms 后又迅速进入敌方伤害，再约 700ms 后进入下一步，导致感受更像“答错也奖励很多，而且信息一闪而过”，而不是“低质量调用让我多付出了战斗代价”。

因此 Candidate B 的阻塞点分为两项：

1. **战斗反馈节奏不清楚**；
2. **failed / no-call 40% 下的恢复组件仍可能显得过强**。

## 2. 战斗反馈节奏 Sol 裁决

下一轮必须先保证玩家能读懂一个完整回合。

非击杀回合冻结节奏：

1. 玩家技能结果立即结算并显示；
2. 技能结果至少稳定停留 `1200ms`；
3. 若存在实际回复，必须使用绿色 `+N HP` 明确显示本次真实回复量；
4. 技能结果停留结束后，进入敌方行动预备 `400ms`，此阶段不改变 HP；
5. 敌方伤害正式发生，使用红色 `-N HP` 显示本次真实伤害，同时更新 HP；
6. 敌方伤害结果至少稳定停留 `1200ms`；
7. 以上信息稳定后，才开放下一回合技能选择。

总原则：

> **玩家不需要靠反应速度“追”战斗信息。技能结果与敌方代价必须分成两个可读阶段。**

击杀回合：

- 技能结果仍至少显示 `1200ms`；
- 敌方死亡后不出现敌方行动预备与伤害阶段；
- 然后进入战后结果。

本轮不新增正式技能动画、复杂演出、音效系统或可跳过时间轴。

## 3. 低质量倍率重新 Review

下一轮不直接冻结 25% 为正式规则，只作为 **Candidate C 候选测试**。

Candidate C 候选倍率：

- independent：`1.00`，不变；
- supported：`0.70`，不变；
- failed：`0.25`；
- no-call：`0.25`。

failed 与 no-call 必须成对调整，禁止只削 failed。

理由：若 failed 单独降为 25%，而 no-call 仍为 40%，就会出现“没有英语调用反而比尝试后答错更强”的系统倒挂。

## 4. Candidate C 下的技能组件预期

敌人继续使用 Candidate B 压力：

- 玩家 Max HP：`48`
- 敌人 Max HP：`80`
- 敌人基础伤害：`14`

技能基础值不变。

### 水音 failed / no-call 25%

- 伤害：`18 × 0.25 = 4.5 → 5`
- 下一击削弱：`20% × 0.25 = 5%`

### 回潮 failed / no-call 25%

- 伤害：`10 × 0.25 = 2.5 → 3`
- 回复：`22 × 0.25 = 5.5 → 6`

所以低质量回潮在敌伤14下，如果存在足够缺失 HP：

- 先 `+6 HP`
- 再承受约 `14` 伤害
- 净生存结果约 `-8 HP`

与 independent 回潮 `10伤害 + 22回复` 的差距会比 Candidate B 更明显。

## 5. 代表性数值曲线

在现有 Candidate B 敌人 80/14、不改技能基础值的前提下，Candidate C 的代表性路径预计：

- 全 independent：仍约第5个玩家行动胜利，约剩 `23 HP`；
- 一次 failed（水音）后恢复 independent：约第6个玩家行动胜利，约剩 `10 HP`；
- 连续两次 failed（水音）后再恢复：代表路径仍会在击杀前战败；
- 持续 failed：应更早战败；
- failed 回潮：回复约 `6`，不再给人“答错也回很多”的强烈印象；
- repair 后同词回到 independent 时，恢复、伤害和生存差异应更明显。

这些只作为 Candidate C 验证目标，不是主线正式平衡。

## 6. 为什么本轮不继续只加敌伤

Candidate B 已经出现：

- 全 independent 5回合可胜；
- 一次 failed 可救；
- 连续两次 failed 代表路径会败；
- 持续 failed 会败。

说明“回合压力”已经接近目标。继续单纯把敌伤从14再往上抬，可能先伤害“认真作答但偶尔失误”的玩家，而仍没有解决玩家读不懂技能与敌方行动两个阶段的问题。

因此下一轮优先修：

1. 读得懂；
2. 再测试低质量技能组件是否仍太宽松。

# BOSS压力回调与打击表现V2

2026-08-31用户实机：BOSS过猛，动画呆，技能表现弱。V1工程通过不代表体验通过；本轮明确修正。

范围仍仅 `/prototype/battle-ui`、独立验证、效果资产与交接/记忆。主线、旧原型、澜歌技能数值、HP48/60和存档不动；不新增技能/状态/正式剧情。

- 新 `gatekeeper-v2`：石拳14、震击28，维持固定交替。V1的16/36与fixture8历史配置保留。
- 新压力预期：连续水音4回合胜/余4HP，水水潮水4回合胜/余23HP，全回潮6回合胜/余48HP；不靠必死强制玩家用指定招式。
- 动画优化前摇→快速出手→短促命中停顿→受击→回位；石拳有贴近目标的前冲，震击有下砸与传向目标的地面冲击。不能只是原地匀速摆臂和一条细线。
- 保持水音已认可样板；优化回潮收手与回复、静波抬手撑住的动作曲线与特效层次。延续原立绘和原布局，不重画角色。
- 命中继续是40%（BOSS960ms），短停顿是显示keyframe，不暂停战斗逻辑、不重复结算；玩家结果可读时间不缩短。
- 加一张独立金色/青色冲击效果原图，用黑底screen合成，减少单纯几何光圈感；不加入全屏闪白、屏幕UI晃动、声音或新引擎。
- 只让战场内容轻震，HP和按钮不移动；减少动态效果模式完全关闭动作和特效。
- 验证历史39+28项、新V2专项、类型、构建、核心回归、lint和冻结范围diff；未做浏览器/手机测试不得报告实机通过。记录GitHub并私有发布后停止。

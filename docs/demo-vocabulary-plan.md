# 试玩词汇方案

## 唯一数据源

正式来源为《英语都市_5505单词分类审查表.xlsx》主表“5505词审查”。`wordId`是唯一主键。代码不得覆盖Excel的中文义项、音标、词性、主题、主句英文或主句中文。

当前`app/vocabulary.ts`是从正式Excel机械生成的80词冻结子集。已核验：80个唯一`wordId`、80 L1、36个L2候选标记、24个L3候选标记，源字段差异0。

## 筛选原则

`考研阅读价值 > 三层训练价值 > 目标学生当前难度 > 剧情适配`

- 总计80词：简单词50、高频词27、中频词3。
- 学习包：LP01 6、LP02 9、LP03 7、LP04 10、LP05 6、LP06 8、LP07 9、LP08 10、LP09 7、LP10 8。
- 学习包只组织内容，不对应某一EP，也不直接触发剧情。

## 三层规则

- L1：英文单词→四选一中文义项。当前80词均可运行。
- L2：限定sense的同义替换。36词候选，但正式题目尚未制作。
- L3：使用Excel主句英文判断句中义。最多24词候选，但正式题目尚未制作。
- 主循环取消填空。源句无法清楚体现目标义时退回L1/L2，禁止自动改句。

## FSRS与Mastery Layer

- `ts-fsrs`只负责何时再次出现。
- Mastery Layer只负责本次允许考到L1/L2/L3的哪一层。
- 当前真实状态：FSRS已接入；Mastery升降层尚未实现，运行时只出L1。
- 答错交给FSRS Again，并允许在战斗中优先复现该`wordId`。

## 必须Review

1. 36道L2的答案、干扰项、senseNote和词义边界。
2. 24道L3源句是否真正体现目标义，中文主句是否完整可靠。
3. `maintain/account/concern/issue/clear`等多义词不得出现两个都说得通的选项。
4. 探索力、新词/复习/纠错奖励值必须配置化，实机后再定。

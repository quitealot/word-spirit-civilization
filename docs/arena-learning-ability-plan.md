# 竞技场学习能力方案

## 产品目标

异步竞技的辨识度来自“守擂者真实英语掌握数据参与攻、防和反击”，不是把普通AI套上玩家名字。EP08开放但不强制，主线无需竞技即可通关。

## 守擂快照

每词保存：`wordId`、当前层、稳定度、近期正确率、平均反应时、最近复习时间、到期状态。总体保存L1/L2/L3强项比例、7日保持率和近期遗忘词池；队伍保存等级、星级、技能和共鸣。

付费数值不得进入匹配核心。无后端试玩可以使用固定匿名快照，但必须明确标记“测试守擂记录”。

## 一回合规则

1. 挑战者选技能，系统从挑战者到期词池出题。
2. 挑战者答对时技能完整发动；Hard/超时正确可降效；答错为失败或低效。
3. 守擂AI的防守强度来自守擂者对应`wordId`或同层同主题词的历史稳定度。
4. 挑战者答错时，守擂者对该词掌握越稳、反应越快，反击越强。
5. 守擂方攻击时给挑战者出题，挑战者答对可闪避或减伤。

## 匹配与防刷基线

- 英语掌握段35% + 当前学习进度25% + 有效战力25% + 近期竞技表现15%。
- 优先差值±10%，不足再扩到±20%。
- 新手前3场不得匹配L3稳定词比例高20个百分点以上的对手。
- 每日首胜与前三场给完整奖励；同一对手每日只计一次排名收益。
- 奖励限外观碎片、图鉴线索和称号进度，不出售英语胜率。

## 当前真实状态

- EP08后有一个明确标为“测试守擂记录”的本地面板。
- 当前只用固定说明和三步按钮模拟回合；没有真实逐词快照、匹配、攻击、防守、反击、排行或后端。
- 现有实现不能用于验证“主动竞技”指标，只能验证入口文案和玩家是否愿意点击。

## Review门

Sol需先确认：快照字段、隐私边界、匹配权重、反击映射、超时/Hard效果、首场长度及测试快照格式。确认后再实现真实竞技闭环。

# 3D 战斗上限样片 V1

用户于 2026-09-01 明确要求“我想看到上限，第一步升级为3d”。本任务将 3D 方向限定为独立可运行样片，不覆盖现有 `/prototype/battle-ui`，不迁移主线、成长、存档或三只语灵全量内容。

## 目标

新增 `/prototype/battle-3d`，用澜歌对雾港守门人展示一次可重复触发的“水音”完整演出：准备、吟唱汇水、镜头推进、释放、Boss 受击与短暂停顿、扣血、收势回场。

样片必须是真实 WebGL 3D：透视相机、空间模型、动态光照、投影、雾与空间特效。首版角色允许使用有明确轮廓与材质分层的风格化 3D 块模，以验证构图与演出；不得称为最终精模、骨骼或正式美术资产。角色组件应可被后续 glTF 模型替换。

## 范围

- 单场景、单技能、单敌人；玩家 48 HP、Boss 60 HP、水音 18 伤仅沿用试玩夹具。
- 保留墨绿、旧金、雾中遗迹与横向对战视觉语言。
- 支持重放、降低动态偏好、WebGL 不可用提示、窄屏布局。
- 不接英语、主线、成长、存档、战中换人、其他技能、音频或新正式设定。
- 不修改现有 battle-ui 的代码、素材和线上入口行为。

## 验收

- 首屏明确为 3D 上限样片并展示双方 HP、技能说明和唯一行动按钮。
- 水音阶段顺序清楚；Boss HP 只在命中阶段从 60 变 42；演出期间不可重复触发；结束后可再次重放。
- Canvas 使用真实阴影和受控像素比，移动端不依赖悬停操作。
- strict TypeScript、build、`git diff --check` 通过；已有专项检查不因本任务放宽。
- 工程通过与动态审美验收分开记录。

## 实机闭环记录

开发环境从合法 EP05 前置状态直接挑战：

1. 战斗首屏先显示芽语三个技能，没有先弹英语题。
2. 选择“叶拍”后调用当前到期词 `grow`。
3. 故意答错后，“叶拍”以配置的 30% 发动：敌方受到 6 点伤害，玩家受到 16 点反击；没有统一显示“失去行动”。
4. 连续答错至 HP 0 后立即战败，EP05 未完成；页面列出 `grow / 错误 / 叶拍 30%`。
5. 进入针对训练并答对后，针对训练来源从 1 变为 0；芽语获得 10 经验、共鸣 +2，探索力从 22 变为 26。
6. 反馈结束后出现“立即再挑战”；点击后双方 HP 重置为 100，战斗回到技能选择阶段，已记录学习与成长保留。

结果：直接挑战 → 技能调用 → 答错折损 → 战败复盘 → 针对训练 → 立即再挑战可连续完成，无剧情文本参与。

## 数据与职责边界

- FSRS继续只决定词何时到期；即时战斗调用不会替代长期复习。
- `Mastery`/题层规则未扩展，运行时仍只使用已批准的 L1。
- 战斗效果读取语灵技能的机器字段 `executionKind`，不由题型决定。
- 战斗薄弱记录可以来自未做章节训练的直接挑战，因此不会因空准备包丢失。
- 同一集、同一词、同一类成长证据不可重复刷；换语灵也不能重复领取同一学习证据。
- 存档迁移至 v6；旧存档由正常迁移函数补齐薄弱词与稳定调用字段。

## Sol Review重点

1. 直接挑战是否仍让玩家理解训练有价值，而非形成“训练可完全忽略”的误读。
2. 各技能错误倍率是否表达了足够不同的技能结果。
3. 薄弱词复盘是否够短，且“立即再挑战”的动机是否明确。
4. 稳定调用与薄弱恢复的经验/共鸣反馈是否过强或过弱。

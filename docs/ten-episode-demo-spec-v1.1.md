# 《词灵》10关试玩版完整内容与执行方案 v1.1

> 状态：正式PASS候选稿。v1.1已按评审修正学习—剧情绑定、FSRS职责、80词价值排序、守门人认知及L2/L3覆盖范围。除本文明确标为“可配置”的数值外，Codex不得自行补写剧情、命名语灵、改词义、改例句、增加世界观设定或更换玩法。

## 0. 产品结论

试玩版不是“把背词页面包一层剧情”，也不是缩小版开放世界。它是移动端优先、界面驱动的精灵收集养成 RPG：

`看伙伴状态 → 学7–10个新词 → 获得探索力 → 点击地图节点 → 对话/战斗 → 收集或成长反馈 → 可选异步竞技 → 留下明日钩子`

单次战斗的30秒循环固定为：

`选语灵技能 → 系统按学习状态出题 → 作答 → 技能反馈 → 敌方行动/反击 → 下一回合`

英语决定技能能否完整发动；语灵决定技能效果。语灵与题型永久解绑。

本试玩有80个新词总池和10个剧情节点，但两者不是一一对应的十个学习单元。正常获得2只语灵、探索充分时可获得第3只；可见角色控制在三只初伴、两只普通野外语灵、一只稀有语灵、一只传说剪影、守门人及两类蚀影以内。

### 1.2 导入规则

1. Excel为唯一词库真源；以`wordId`作主键，绝不以数组下标作主键。
2. 原字段原样保存。本文新增的`episode`、`firstLayer`、`srsPlan`、`synonymPrompt`属于试玩内容配置，不得回写或伪装成Excel字段。
3. 展示词义只取“中文义项”；不从网络或旧308词过渡题库覆盖。
4. 语境题只取该词“主句英文”。主句中文完整时可用于答后解析；不完整时仅显示原中文义项，不展示损坏译文。
5. 80词之外不得在新词教学中出现；干扰项可以从5,505词中取，但必须保存其`wordId`并经过人工题目配置，禁止运行时由模型生成。
6. 同义替换是人工派生的题目关系，不是Excel原字段。每一道必须配置`targetWordId + acceptedAnswer + distractorWordIds + senseNote`；不得把一个词的所有义项都视为同义。

### 2.3 剧情与学习如何真正解耦

- 剧情节点只检查“探索力、前置剧情、必要交互”，不检查“完成某个LP”或“刚学几词”。
- 新词首次正确、到期复习、错词纠正、首次完成竞技均可提供探索力；到期复习是每日主要来源，新词不是唯一门票。
- EP03是纯复习战节点，不触发新词；EP06以获得伙伴和组队为主，不触发固定新词；Boss前优先清到期复习，不强迫补齐某个8词包。
- 玩家可能学完LP01后连续推进EP01与EP02；也可能完成LP02的一部分但当天只推进一个剧情节点；也可能只做复习仍获得一次探索。
- 推荐测试节奏而非硬门槛：EP01开场即可进入；EP02需一次有效学习行为；EP03完成EP02即可；EP04–EP05随累计探索逐步开放；EP06只依赖三次目击；EP07–EP10结合累计探索与前置事件。
- UI禁止显示“本集8个新词”“学习包对应EP”或“背完这些词看下一集”。只显示“今日学习”“到期复习”“探索力”和地图节点状态。

## 3. 三层学习、SRS与出题规则

### 3.1 三层不是三个难度按钮

- L1 单词意思：显示英文单词，四选一中文义项。首次学习只考内容配置采用的目标义，答后展示Excel原“中文义项”全量文本。80词全部必须有L1。
- L2 同义替换：显示单词或含目标义的短语，选择最接近替换。关系由人工配置并限定sense；不允许运行时生成。
- L3 句子语境义：完整显示Excel“主句英文”，加粗目标词，问该句中含义。选项为中文；答后只在源译文完整时显示“主句中文”。
- 主循环取消语境填空。填空只能作为P2额外活动，不能计入80词掌握和探索力。

### 3.2 FSRS与Mastery Layer的唯一职责

不再实现第二套“毕业状态机”。每词只保存两个正交维度：

- `fsrsCard`：由ts-fsrs负责何时再次出现，包括Again/Hard/Good/Easy、到期时间、稳定性和难度。
- `masteryLayer`：只表示这一次允许考到的最深题型，取L1/L2/L3；它不计算下次日期，也不存在STABLE毕业态。

规则：

- 新词首次固定L1。答题结果直接交给FSRS调度。
- 系统根据累计成功证据、最近错误和反应时，从可用内容中选择L1/L2/L3；阈值必须配置化，不在试玩前写死“答对两次”“第几集升级”等规则。
- 答错后由FSRS提前调度；下次题型可保持或降一层，不能因为一次错误清空全部证据。
- 语灵等级、付费、道具不能提升masteryLayer或跳过到期复习。
- 产品分析保留每层正确率和反应时，试玩后再决定阈值，不在客户端另造“稳定毕业率”。

### 3.3 试玩SRS与题池

- 首次L1答错，可在本会话稍后做一次短间隔纠正；正式下一次到期仍完全服从FSRS。
- 第二自然日先呈现FSRS到期队列。完成到期队列给予主要探索力，但玩家不必清空全部新词才能推进剧情。
- 普通学习/战斗题池建议：70%到期词、20%当前新词、10%已学抽检；这是可配置起点，不与某一EP绑定。
- Boss建议：80%到期或近期错词、20%跨层抽检。没有L2/L3内容的词只出L1，不得临时生成高层题。
- 每日建议7–10新词、15–30复习词；试玩十集不强制十天完成，可在3–10天内测，但D1/D2回访必须按自然日记录。

### 3.4 L2/L3优质子集策略

- P0：80词全部完成L1。
- P0：仅36个词制作人工审校L2：reach、increase、remain、achieve、improve、focus、appear、avoid、choose、compare、complete、connect、continue、experience、follow、important、include、prefer、prepare、remember、result、return、value、capable、cautious、complex、disappear、discover、emerge、necessary、obvious、maintain、involve、affect、require、select。
- P0：仅24个词制作人工审校L3：increase、remain、focus、clear、experience、familiar、important、access、benefit、capable、cautious、complex、emerge、necessary、obvious、reliable、maintain、involve、affect、indicate、account、concern、available、assume。
- 其余词试玩阶段只做L1。不得为了“80词三层全覆盖”硬凑同义或语境题。
- L2关系必须记录目标义、可接受答案与边界说明。例如protect与preserve只有“保护”义可近似，不能把preserve的“保存/腌制”义混入；select与choose只在“选择/挑选”义相近。
- L3默认使用Excel主句英文，但若主句不能清楚体现目标义，或源中文句损坏导致无法可靠解析，该词即使在候选名单中也先退回L1/L2，等待人工审校，不自动改写原句。

所有英文单词型答案须在5,505主表中查到并保存wordId；短语型答案标记`answerType=phrase`，不进入新词计数。

## 4. 角色、语灵与资源冻结

### 4.1 NPC

- 岑婆：雾港语灵站负责人，务实、嘴损、懂语灵，不作百科讲解员。
- 阿洛：16–17岁港口跑腿少年，好奇、嘴快、冒失，但遇险会先确认同伴。
- 玩家：有简短回应与选择，不是无人格哑巴。
- 守门人：说话短、具体，只知道这条路以前出过事、有人没有回来；不知道谁抹了石碑、为什么会忘、被抹去的名字意味着什么。

### 4.2 三只初伴（三选一，只得一只）

- 芽语：守护型。技能：叶拍（单体）、护芽（护盾）、扎根（下回合减伤）。
- 烬尾：强攻型。技能：火星（单体）、焰尾（高伤）、蓄火（强化下次）。
- 澜歌：恢复型。技能：水音（单体）、回潮（治疗）、静波（降低敌方下次伤害）。

技能发动前均可能出L1/L2/L3任一到期题；不存在“芽语=词根、烬尾=词义、澜歌=填空”。

### 4.3 其他语灵占位ID

- 绒岚（内部ID：`MIST_PORT_SPIRIT_01`）：第一只野外伙伴，EP04–06跟随，EP06必得。正式名与生物核心已冻结；技能等待独立Review，且与英语题型永久解绑。
- `MIST_PORT_SPIRIT_02`：广场普通野生语灵，仅展示/战斗，不保证获得。
- `MIST_PORT_RARE_01`：EP09稀有语灵。试玩只可追踪与一次挑战，默认不获得。
- `SKY_LEGEND_01`：天空传说剪影，不可战斗、不可获得、不展示名称。
- `MIST_GATEKEEPER_01`：守门人Boss，不作为可收集语灵。

## 5. EP01–EP10完整剧情与自然对白

### EP01｜第一伙伴

场景顺序：雾港近景/异常旧路钩子 → 语灵站室内。功能：先建立阿洛、岑婆与雾港关系，再三选一、初伴标记、L1教学。剧情不绑定固定新词数；首次进入只需完成3个L1教学词。资源复用现有雾港/旧路背景与语灵站背景、岑婆2表情、阿洛2表情、三初伴各2状态、共鸣微光，不新增复杂动画。

## 6. 战斗、组队、养成与收集

### 6.1 1–3只组队

- EP01–05：1只；EP06起2只；如后续测试活动获得第三只则可3只。
- 队伍不满不补NPC、不降低基础能力、不显示红色缺位。
- 每回合选当前语灵和技能；换人不出题且每2回合最多一次，避免拖沓。
- 普通战90–150秒，Boss 4–6分钟；失败保留本轮学习记录，可立即再战或退出。

### 6.2 养成四线

- 等级：完成学习、战斗获得，影响基础数值；不能替代英语作答。
- 星级★1–★5：由稳定掌握、7日保持率、平均识别秒数、陌生文本覆盖率驱动；不售卖升星。
- 技能：等级/剧情节点解锁；技能升级只调效果，不减少学习要求。
- 共鸣：玩家与单只语灵共同完成有效学习和战斗的长期值。界面用动作/纹理变化表达，不展示“再背32词进化”。

试玩中EP06、EP07、EP10各给一次明显共鸣反馈；初伴不完成正式进化，只给可见征兆。玩家应感到“快了”，但看不到精确倒计时。

### 6.3 图鉴与稀有

- 图鉴记录“见过、共鸣、未共鸣、剪影”四态。
- 普通伙伴通过剧情信任获得，不使用捕捉球或抽卡。
- 稀有语灵以可重复线索驱动追踪；试玩只完成1/3，不承诺掉率。
- 传说只给剪影，不弹“SSR”、战力、卡池或预购。

## 7. 异步竞技场：真实英语掌握驱动守擂

### 7.1 数据快照

守擂者设置1–3只语灵后，系统生成不可手改的学习快照：

- 每词：wordId、当前层、稳定度、最近正确率、平均反应时、最近一次复习时间、到期状态。
- 总体：L1/L2/L3强项比例、7日保持率、近期遗忘词池。
- 语灵：等级、星级、技能配置、共鸣；不得把付费数值纳入匹配核心。

本地试玩无后端时允许用固定匿名测试快照，但UI必须标记“测试守擂记录”，不能伪装实时真人。

### 7.2 匹配

匹配评分：英语掌握段35% + 当前学习进度25% + 语灵有效战力25% + 近期竞技表现15%。优先差值±10%，找不到再扩到±20%。新手前3场不得匹配高于其L3稳定词比例20个百分点的对手。

### 7.3 一回合如何结算

1. 挑战者选技能，系统从挑战者到期词池出题。
2. 挑战者作答后，战斗层独立评为full/partial/miss并结算技能；FSRS的Again/Hard/Good/Easy只由学习调度器计算，不能与战斗效果直接绑定。
3. 守擂AI防守强度来自守擂者对应`wordId`或同层同主题词的历史稳定度，而不是随机命中。
4. 挑战者答错触发反击机会。若守擂者该词稳定度高、反应快，反击100%；一般为60%；守擂者本人也常错则20%或失败。
5. 守擂AI攻击时给挑战者出题；挑战者答对可闪避/减伤。故双方英语数据都真正进入攻、防、反击。

示例：挑战题为`protect`。挑战者答错；守擂快照显示该玩家对w1233已有充分L3成功证据且7日保持良好，则守擂语灵强反击。若守擂者w1233近期连续Again，反击只产生弱效果。

### 7.4 防刷与奖励

- 每日首胜和前三场给完整奖励，之后只给少量练习奖励；失败不扣学习进度。

### 10.3 投资判定指标

| 验证 | 通过线 | 强通过线 | 失败警报 |

| D1自然回访（无人催促） | ≥35% | ≥50% | <25% |

辅助门槛：

- EP01三选一完成率≥90%；三只选择占比不得出现单只>70%（若出现，检查表现与强度误导）。
- 首次学习完成率≥80%；平均单集新词环节≤6分钟；首日EP01–03中位总时长15–25分钟。

- 次日到期复习完成率≥60%；D1回访者中≥70%完成复习后继续至少一个游戏行为。
- 竞技首场完成率≥80%，首场后主动再战≥30%；若竞技打开高而完成低，优先查题池公平和回合长度。
- 剧情跳过率：EP01≤25%，EP08/EP10≤35%；若高于此值，访谈确认是文本节奏还是玩家只想战斗。
- 80词wordId追溯率100%；源字段被运行时覆盖0条；未知/损坏中文句被擅自修复0条。

### 10.4 继续投资的决策规则

- 建议继续投入：四项核心至少3项过通过线，且D1必须过线；无重大数据真实性或学习体验问题。

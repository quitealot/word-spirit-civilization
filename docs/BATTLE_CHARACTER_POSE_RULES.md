# 展示立绘与战斗动作分工

来源：用户明确确认“立绘有姿势，正常战斗就正常站姿”。

- 展示立绘：允许歪头、回眸、摆姿势，突出个性。原图保留，不能因做战斗图而覆盖。
- 战斗待机：身体自然站稳，头、颈、胸口朝向对手；四足角色前后腿结构清楚，尾巴从臀部自然向后延伸。
- 向前跑：头与胸口处于前进侧，前爪配合前进，后腿蹬地；不能身体逆行、仅把头扭向目标。
- 扫尾：先明确转身，尾根带动尾部形成扫击，命中时才显示伤害。
- 返回：按当前烬尾已确认方案，朝原位正向跳回，落地后再转向对手；不倒着滑回。
- 收招：恢复战斗待机，再接敌方行动。

检查顺序：身体结构 → 移动方向 → 发力动作 → 接触点与伤害 → 回位落地 → 衔接。不能只检查鼻尖朝向或CSS镜像标记。

允许复用角色设计和画风，不要求每个动作重画整套角色。确需姿势变化时使用独立动作素材；不得仅平移概念立绘来宣称完整动作已做完。素材检查与工程检查不等于动态试玩通过。

范围：当前先应用烬尾独立battle-ui。其他语灵后续制作同样遵守，不由此解冻主线、美术以外系统或正式剧情。

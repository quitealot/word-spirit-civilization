# 3D 战斗上限样片 V1 交接

用户授权：2026-09-01“我想看到上限，第一步升级为3d”。实现为独立 `/prototype/battle-3d`，没有覆盖现有 2D battle-ui。

## 已实现

- Three.js `0.180.0` + React Three Fiber `9.6.1`，匹配当前 React 19。
- 真 WebGL 3D：透视镜头、风格化角色块模、遗迹柱与环形地面、雾、PBR 基础材质、动态灯光、真实投影。
- 澜歌对雾港守门人单技能样片：gather → release → impact → recover；命中阶段 Boss 60 → 42，期间锁定重复触发，结束可重放。
- 运镜分别聚焦吟唱与命中；水流环、粒子、冲击补光、Boss 受击抖动与屏幕命中闪光。
- 受控像素比 `1–1.65`、高性能 GPU 偏好、WebGL 失败提示、移动端布局和降低动态模式。

## 边界与事实口径

当前角色是程序化风格 3D 块模，用于验证镜头、空间、材质和技能演出，不是最终精模、UV 贴图、骨骼动画或可量产资产。角色实现被隔离在样片组件中，后续可换标准 glTF，但本轮没有采购、生成或承诺精模。

水音 18 伤、48/60 HP 只沿用现有试玩夹具，不宣布正式纯游戏平衡。未新增英语、剧情、音频、成长、存档、战中换人或其他技能；旧 `/prototype/battle-ui` 与主线没有代码改动。

3D 页面会单独加载 Three.js 运行代码，因此其客户端包比 2D 页大；旧页面不引用该入口。后续进入真实模型制作前，应先由用户裁决 3D 构图与演出方向，再决定是否投入角色建模、绑定与动作。

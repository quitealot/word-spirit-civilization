## 1. 项目一句话

《语灵》是一款面向**纯零基础/基础断层英语学习者**的移动端叙事养成 RPG：用真实游戏行动把英语教会，让前面学会的词和结构成为后面学习更难内容的脚手架；语灵成长用于把“愿意回来玩”和“真的学会英语”连接起来。

有基础的用户可以把它当游戏和英语维护工具，但教学设计的第一服务对象始终是零基础用户。

## 2. 制作形态

当前技术与制作能力承载的是：

- 移动端 Web；
- 场景背景图；
- 人物/语灵立绘；
- 节点式交互；
- 对话与短叙事；
- 技能/战斗界面；
- 分层图片、位移、缩放、透明度、粒子、屏幕震动等轻量动画/特效；
- 后期可逐步升级演出，但不改变节点式关卡逻辑。

明确不做：开放世界、摇杆自由走路、3D 大地图、实时自由探索。若一个教学设计只有“玩家自由走过去”才能成立，默认应重构为节点/场景交互。

## 3. 正式术语

- 游戏名：**《语灵》**。
- 伙伴/生物：统一称 **语灵**。
- “词灵”是废弃旧称；旧仓库文件名/仓库名可保留技术历史，但新玩家内容不得使用旧称。
- 玩家不是天选之子。
- NPC 不解释“英语世界/旧文明英语/语言力量”；英语只作为学习/操作层出现。

## 7. 零基础教学最高原则

目标不是“把题做对”，而是让原本不会的学生真正会。

核心规则：

1. `Unknown Budget = 1`：一次学习尽量只有一个主要未知知识（新词/新词义/新搭配/新句型/新语法都算）。
2. 以前学会的内容必须反复作为新内容脚手架。例如先会 `water`，以后可用于学习 `clean water`、`provide water` 等自然组合。
3. 不为了复用旧词制造垃圾英语；语言自然性与当前可理解性必须同时成立。
4. 中文是合法脚手架。零基础阶段不能用陌生英语解释陌生英语。
5. 教学优先在世界行动中发生，而非固定“5 张词卡”。
6. 教学脚手架可以短暂出现并消失，但已掌握英语要在后续真实事件中自然复现。
7. 如果世界提示、单词提示、拆词支架后仍不会，最终可以明确给出完整中文意思；教学效果优先于“假装没有老师”。给完答案后必须再次让玩家亲手完成。
8. 前面学会的简单词不是新手垃圾内容，而是未来几千词的教学基础设施。

推荐教学链：

`世界需求发生 → 命名英语 → 马上使用 → 旧知识帮助新知识 → 逐步撤除支架 → 英语直接驱动游戏行动`

## 8. 学习状态与战斗资格：V2 当前裁决

单词学习证据至少区分：

- `Introduced`：真正教过；
- `Guided`：有支架时成功调用；
- `Retrieved`：无中文答案时独立提取；
- `Used`：依靠该英语真实完成过游戏行为；
- `Maintained`：**词已经达到 Used 之后**，后续维护成功的证据状态。

“见过一次”不等于掌握。

V2 战斗层取词正式固定为：

`Used-or-Maintained + battleEligible`

**Review A / 融合切片 V1/V1.1 中“与技能/行动语义匹配”的战斗层限制已经被 V2 覆盖，不再有效。**

因此：

- `Introduced / Guided / Retrieved` 不进入战斗池；
- `Used + battleEligible` 可以进入；
- `Maintained + battleEligible` 也可以进入；
- 世界教学仍要求词义与世界事件自然对应；
- 战斗技能不拥有专属词池；
- 同一技能可以调用不同合格词，不同技能也可以调用同一合格词；
- 直接挑战不能首次教授陌生英语。

## 9. 技能 × 英语系统 V2：当前权威规则

V2 权威规格：

1. `docs/SKILL_ENGLISH_SYSTEM_V2.md`
2. `docs/SKILL_ENGLISH_SYSTEM_V2_ENGINEERING_LOCK.md`
3. `app/AGENTS.md`

核心契约：

> **技能决定这一回合做什么；英语决定这件事这次发挥多少。**

即时英语发挥只用三档：

- 无帮助独立正确：`1.00`；
- 使用轻度支架后正确：`0.70`；
- 错误 / 依赖完整答案后完成：`0.40`。

反应时间只后台记录，不直接影响即时战斗倍率。

`Maintained` 视为 Used 之后的维护状态，仍可进入战斗池。

统一取整：

- 伤害、回复、护盾等整数型组件：所有倍率完成后只 `Math.round` 一次；
- 百分比型效果逻辑层保留小数，最终整数伤害只在百分比结算完成后取整一次。

完全没有合格词时：

- 仍允许直接挑战；
- 不出现陌生英语；
- 不创造“基础技能20伤害”等临时技能；
- 仍使用玩家真实技能；
- Phase A `noCallMultiplier = 0.40`，与 failed 数值相同但配置键独立；
- no-call 不产生薄弱词。

战斗结算顺序、削弱/减伤/护盾/回复、击杀后是否反击等工程语义，以 `docs/SKILL_ENGLISH_SYSTEM_V2_ENGINEERING_LOCK.md` 为准，Codex 不得自行决定。

首轮体验验收仍保留四句话：

1. 我刚才是在游戏里学会这个词的。
2. 战斗里再看到它，我知道自己在用什么。
3. 答稳以后，语灵真的明显更强。
4. 答错以后，我愿意把刚才那个词弄明白再打一次。

## 11. 词表与学习底座

- 正式 5505 Excel 是词汇唯一真源。
- 任何新词都必须读取真实 `wordId`、正式中文释义与源字段。
- 禁止编造 `wordId`、释义、正式例句。
- 80 词试玩池仍来自正式 Excel；L2/L3 受 Review 门控制，不自动生成正式内容。
- `ts-fsrs` 是唯一时间调度底座；不要新增第二套调度器。
- 词掌握属于玩家，不为不同语灵重复学习同一个词。
- 技能与词/题型不硬绑定；V2 战斗层不要求词义与技能语义绑定。

## 12. 初伴与成长

三只初始语灵：芽语、烬尾、澜歌。

- 芽语：守护倾向；
- 烬尾：强攻倾向；
- 澜歌：恢复/支援倾向。

成长概念保持区分：

- 等级：有效训练与实战带来的成长；
- 星级：长期真实掌握质量；
- 技能：等级等条件解锁的真实能力；
- 共鸣：与该语灵共同经历的关系/进化方向信息，不是普通 XP。

不要自行新增完整进化树、星级阈值或成长数值。

## 1. 项目身份

《语灵》是一款面向**纯零基础/基础断层英语学习者**的移动端叙事养成 RPG。

核心目标：

- 用真实游戏行动把英语教会；
- 前面学会的词和结构，成为后面学习更难内容的脚手架；
- 语灵成长用于连接“愿意回来玩”和“真的学会英语”。

有基础用户可以游玩和维护英语，但教学设计第一服务对象始终是零基础用户。

产品形态固定为：移动端 Web、背景/立绘、节点交互、对话、技能战斗、轻量动画/特效。

明确不做：开放世界、摇杆自由走路、3D 大地图、实时自由探索。

## 6. 零基础教学最高原则

目标不是“测试学生会不会”，而是把不会的真正教会。

核心规则：

1. `Unknown Budget = 1`：一次学习尽量只有一个主要未知知识；
2. 已学内容必须成为新内容脚手架；
3. 不用多个陌生英语解释另一个陌生英语；
4. 中文是合法支架；
5. 教学优先在世界行动中发生，而不是固定单词卡；
6. 教学链：`世界需求发生 → 命名英语 → 马上使用 → 旧知识帮助新知识 → 逐步撤支架 → 英语驱动行动`；
7. 如果世界提示、单词提示、拆分支架后仍不会，可以给完整中文意思，然后必须再让玩家亲手完成；
8. 已掌握简单词是后续几千词的教学基础设施。

学习证据至少区分：

- `Introduced`
- `Guided`
- `Retrieved`
- `Used`
- `Maintained`：只能发生在词已经达到 `Used` 之后的维护成功状态。

## 7. 技能 × 英语系统 V2

权威规格：

1. `docs/SKILL_ENGLISH_SYSTEM_V2.md`
2. `docs/SKILL_ENGLISH_SYSTEM_V2_ENGINEERING_LOCK.md`
3. `app/AGENTS.md`

核心契约：

> **技能决定这一回合做什么；英语决定这件事这次发挥多少。**

当前冻结：

- 战斗取词：`Used-or-Maintained + battleEligible`；
- 战斗层**不再要求**词义与技能语义匹配；
- 世界教学层仍要求语义自然；
- 技能不拥有专属词池；
- 玩家先选技能，再确定本次英语调用；
- independent / supported / failed = `1.00 / 0.70 / 0.40`；
- 反应时间只后台记录，不影响即时倍率；
- 完全没有合格词时，使用真实技能独立 `noCallMultiplier = 0.40`；
- no-call 不产生陌生英语、不生成薄弱词、不创造临时基础技能；
- 统一取整与战斗结算顺序以工程锁定文档为准。

## 9. 当前阶段：Phase B

Phase B 产品规格：

`docs/TEACH_BATTLE_REPAIR_PHASE_B_SPEC.md`

状态：`PRODUCT SPEC FROZEN / NOT YET IMPLEMENTING`

Phase B 只验证这条连续闭环：

`语灵站日常完成 → 直接进入测试战斗 → 暴露真实薄弱词 → 针对训练 → 立即再战`

目标：消除目前“教学原型 + 战斗原型”拼接感，让玩家自然理解：

1. 战斗里的词就是自己刚刚真实用过的词；
2. 战后只复习刚才真实卡住的词；
3. 修复后马上再战时，能明显感到这次更顺。

Phase B 连续路径必须：

- 教学最后真实行动后，最多一次继续操作进入战斗；
- 不经过现有教学总结页和融合切片菜单；
- 不展示 `Used / battleEligible / evidence` 等开发术语；
- 第一次来自语灵站日常的战斗调用可用一次性轻提示 `刚才用过` 建立因果；
- 战后只处理本场真实薄弱 `wordId`，同词一场只补一次；
- 每个薄弱词只做“重新建立意义 → 再独立确认一次”；
- 补弱后不回菜单，直接再战；
- 当前两词原型中，被修复词须在前 2 次英语调用以内再次出现；
- 再战独立正确时直接从技能 100% 实际效果感受改善，不弹额外进步报告；
- 第一战没有真实薄弱词时直接结束，不伪造针对训练。

Phase B 产品验收五句话：

1. 我没有感觉自己从学习页跳去了另一个 Demo。
2. 战斗里这个词出现时，我知道它就是刚才用过的东西。
3. 刚才卡住哪个词，战后就只回来哪个词。
4. 复习完马上又碰到它时，我明显觉得这次更顺。
5. 整个过程像一次连续经历，而不是学习 → 考试 → 错题本三个模块。

# scripts/AGENTS.md

本文件对 `scripts/` 下的校验/迁移/测试脚本生效，是根目录 `AGENTS.md` 的补充。

若脚本任务涉及战斗、语灵技能、英语调用、battleEligible、技能倍率或技能数值，必须先读取：

`docs/SKILL_ENGLISH_SYSTEM_V2.md`

V2 规格优先于 Review A 与旧 V1 代码。校验脚本必须验证冻结规格，而不是为了让旧实现通过而放宽规则。

禁止自行改动：

- `Used + battleEligible` 战斗取词边界；
- 战斗层“词不与技能语义绑定”；
- 100% / 70% / 40% 质量倍率；
- 九个初始技能 V2 原型效果；
- “技能决定做什么，英语决定发挥多少”的核心契约。

发现规格与实现不一致时，应让实现失败并报告，不得在 validator 中偷偷兼容错误行为。
